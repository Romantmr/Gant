## 🔧 Как работает умная загрузка:

### 1. Полифиллы загружаются первыми
```html
<script src="js/polyfills.js"></script>
```
Добавляют поддержку современных функций в старые браузеры.

### 2. Проверка поддержки браузера
```javascript
if (typeof Symbol === 'undefined' || !window.Map || !window.Set) {
    // Загружаем ES5 версии для старых браузеров
    document.write('<script src="js/utils-es5.js"><\/script>');
    // ... остальные ES5 файлы
} else {
    // Загружаем ES6 версии для современных браузеров
    document.write('<script src="js/utils.js"><\/script>');
    // ... остальные ES6 файлы
}
```

### 3. Автоматический выбор версии
- **Современные браузеры** → ES6 версии (быстрее, меньше кода)
- **Старые браузеры** → ES5 версии + полифиллы (полная совместимость)
