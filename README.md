# Gantt Chart Platform

Современная веб-платформа для создания и управления диаграммами Ганта с полным функционалом ProjectLibre.

## 🚀 Возможности

### Основные функции
- **Создание и управление задачами** - добавление, редактирование, удаление задач
- **Диаграмма Ганта** - визуальное представление проекта с временной шкалой
- **Управление зависимостями** - связывание задач между собой
- **Отслеживание прогресса** - контроль выполнения задач
- **Иерархическая структура** - создание подзадач и сводных задач
- **Различные типы задач** - обычные задачи, вехи, сводные задачи

### Дополнительные возможности
- **Поиск и фильтрация** - быстрый поиск задач по различным критериям
- **Экспорт/импорт** - сохранение проектов в JSON и CSV форматах
- **Автосохранение** - автоматическое сохранение изменений
- **Адаптивный дизайн** - работа на различных устройствах
- **Горячие клавиши** - быстрое выполнение операций
- **Контекстные меню** - удобное управление задачами

## 🛠 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - современные стили с поддержкой темной темы
- **JavaScript ES6+** - модульная архитектура
- **LocalStorage** - локальное сохранение данных
- **Font Awesome** - иконки интерфейса

## 🚀 Установка и запуск

### Для Netlify (рекомендуется)

1. Загрузите все файлы проекта в репозиторий GitHub
2. Подключите репозиторий к Netlify
3. Настройте автоматическое развертывание
4. Приложение будет доступно по вашему домену Netlify

### Локальный запуск (для разработки)

1. Клонируйте репозиторий:
```bash
git clone <your-repo-url>
cd Gant
```

2. Запустите локальный сервер (например, с помощью Live Server в VS Code)
3. Откройте `http://localhost:3000` в браузере

## 📖 Руководство пользователя

### Создание проекта

1. Нажмите кнопку **"Новый проект"** в шапке приложения
2. Введите название проекта
3. Начните добавлять задачи

### Работа с задачами

#### Создание задачи
1. Нажмите кнопку **"Добавить задачу"** в панели инструментов
2. Заполните форму:
   - **Название** - обязательное поле
   - **Дата начала и окончания** - автоматически рассчитывается длительность
   - **Прогресс** - процент выполнения (0-100%)
   - **Приоритет** - низкий, средний, высокий, критический
   - **Исполнитель** - ответственный за задачу
   - **Зависимости** - ID задач, от которых зависит текущая
   - **Описание** - дополнительная информация

#### Редактирование задачи
- **Двойной клик** на задаче в списке
- **Контекстное меню** (правый клик)
- Кнопка **"Редактировать"** в панели инструментов

#### Удаление задачи
- Выберите задачу и нажмите **Delete** или кнопку **"Удалить"**
- Контекстное меню → **"Удалить"**

### Управление диаграммой Ганта

#### Масштабирование
- Используйте выпадающий список **"Масштаб"** в панели инструментов
- Доступны режимы: Дни, Недели, Месяцы, Кварталы

#### Навигация
- **"Сегодня"** - переход к текущей дате
- **"По размеру"** - подгонка под размер экрана
- **Прокрутка** мышью или клавишами

#### Перетаскивание задач
- **Перетаскивание полосы** - изменение длительности
- **Перетаскивание ручек** - изменение дат начала/окончания

### Управление зависимостями

1. Создайте задачи, которые должны быть связаны
2. В форме редактирования задачи укажите **"Зависимости"**
3. Введите ID задач через запятую (например: "1,3,5")
4. Зависимости отобразятся стрелками на диаграмме

### Экспорт и импорт

#### Экспорт проекта
1. Нажмите кнопку **"Экспорт"** в шапке
2. Выберите формат:
   - **JSON** - для резервного копирования и обмена
   - **CSV** - для работы в Excel/Google Sheets

#### Импорт проекта
1. Нажмите кнопку **"Открыть"** в шапке
2. Выберите файл проекта (.json)
3. Проект будет загружен и отображен

## 🎨 Настройка внешнего вида

### Темная тема
Приложение автоматически определяет предпочтения системы и применяет соответствующую тему.

### Адаптивность
- **Мобильные устройства** - оптимизированный интерфейс для сенсорного управления
- **Планшеты** - адаптированная панель инструментов
- **Десктоп** - полный функционал с горячими клавишами

## 🔧 Настройки

### Автосохранение
- Включено по умолчанию
- Сохранение каждые 30 секунд
- Данные сохраняются в localStorage браузера

### Календарь
- Рабочие дни: понедельник - пятница
- Рабочие часы: 9:00 - 17:00
- Поддержка праздничных дней

## 📊 Типы задач

### Обычная задача
- Основной тип для большинства работ
- Имеет дату начала, окончания и длительность
- Поддерживает отслеживание прогресса

### Веха (Milestone)
- Ключевые события проекта
- Не имеет длительности (отображается как ромб)
- Используется для отметки важных этапов

### Сводная задача
- Группирует несколько связанных задач
- Автоматически рассчитывает общую длительность
- Поддерживает иерархическую структуру

## 🔍 Поиск и фильтрация

### Поиск задач
- Поиск по названию, описанию, исполнителю
- Результаты отображаются в реальном времени
- Подсветка найденных элементов

### Фильтры
- **По типу** - задачи, вехи, сводные
- **По статусу** - не начато, в процессе, завершено
- **По приоритету** - низкий, средний, высокий, критический
- **По датам** - фильтр по временному диапазону

## 🚨 Устранение неполадок

### Проблемы с сохранением
- Проверьте, включен ли JavaScript в браузере
- Убедитесь, что localStorage доступен
- Очистите кэш браузера при необходимости

### Проблемы с отображением
- Обновите страницу (F5)
- Проверьте консоль браузера на ошибки
- Убедитесь, что все файлы загружены корректно

### Проблемы с производительностью
- При работе с большими проектами используйте фильтры
- Регулярно экспортируйте проекты для резервного копирования
- Закрывайте неиспользуемые вкладки браузера

## 🤝 Поддержка

При возникновении проблем:
1. Проверьте консоль браузера (F12)
2. Убедитесь, что используется современный браузер
3. Попробуйте очистить кэш и перезагрузить страницу
